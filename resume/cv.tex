\subsection{Resync: UPI Autopay Recovery Platform \hfill \normalfont\textit{2026}}
\noindent
\textit{Live at} \href{https://resync.biz}{\textcolor{blue}{\underline{resync.biz}}} \enspace\textbar{}\enspace
\textit{GitHub:} \href{https://github.com/mandar1045/Resync}{\textcolor{blue}{\underline{github.com/mandar1045/Resync}}}

\vspace{4pt}
\noindent
\textbf{Overview:} Resync is the recovery layer for India's UPI Autopay ecosystem. Merchants register their existing autopay customers; Resync watches every expected charge and when one fails, it executes smart retries on the merchant's own payment gateway account. Pricing is success-based: 3\% of recovered revenue. The platform supports both \textbf{direct recovery} (Resync charges on merchant's connected Razorpay/Cashfree keys) and \textbf{delegated recovery} (merchant charges on Resync's instruction, keeping money-moving secrets in their own infra).

\vspace{4pt}
\noindent\textbf{Architecture \& Technical Details:}
\begin{itemize}
  \item Architected a \textbf{9-microservice} platform in \textbf{Go} with \textbf{gRPC/Protobuf} service contracts:
    \begin{itemize}[label=$\circ$, leftmargin=1em, itemsep=0pt]
      \item \textbf{auth-svc} — Identity management, API key issuance (test/live keys), Supabase JWT verification
      \item \textbf{sub-svc} — Subscription state machine (pending → active → past\_due → cancelled), autopay lifecycle
      \item \textbf{payment-svc} — Multi-gateway abstraction (Razorpay, Cashfree, PhonePe), idempotent charge execution, mandate management, AES-256-GCM credential encryption
      \item \textbf{dunning-svc} — Smart retry engine with UPI failure code classifier (30+ NPCI/Razorpay/Cashfree codes mapped to 8 internal categories), 4 retry strategies, delegated recovery with nudge sweeps
      \item \textbf{invoice-svc} — GST-compliant invoice generation, PDF rendering, S3/MinIO storage, platform fee collection via Razorpay Payment Links
      \item \textbf{webhook-svc} — Outbound event delivery with HMAC-SHA256 signature verification, retry with exponential backoff
      \item \textbf{checkout-svc} — Hosted checkout pages and recovery links for end-customer payment re-authorization
      \item \textbf{billing-cron} — Periodic billing sweep, autopay-missed detection, gateway mandate sync
      \item \textbf{api-gateway} — REST→gRPC translation, rate limiting, auth middleware, Supabase JWT and API key dual-auth
    \end{itemize}

  \item Designed \textbf{UPI failure code classifier} that normalizes 30+ raw NPCI/gateway codes into 8 internal categories and routes to 4 context-aware retry strategies:
    \begin{itemize}[label=$\circ$, leftmargin=1em, itemsep=0pt]
      \item \textbf{Salary-day:} insufficient funds (U30, Z9) → retry on inferred pay-day (1st/15th IST) using historical payment observation streams
      \item \textbf{Exponential backoff:} technical errors (U16, BT) → 2h, 4h, 8h doubling backoff
      \item \textbf{Next-day:} limit exceeded (U68, Z8) → retry next day 10:30am IST
      \item \textbf{Hard fail:} mandate revoked/expired (U14) → immediate subscription cancellation, no retry
    \end{itemize}

  \item Orchestrated event-driven pipeline using \textbf{Apache Kafka} (via Redpanda) with \texttt{subscription\_id} partition keys ensuring strict event ordering; combined with \textbf{Redis SETNX distributed locks} (TTL 30s) and structured idempotency keys (\texttt{charge:\{sub\_id\}:\{cycle\}}) guaranteeing \textbf{zero double-charges} even under concurrent cron workers.

  \item Implemented \textbf{recovery attribution system} with 5 attribution types (resync\_charge, resync\_settled, resync\_delegated, resync\_assisted, organic) and a 72-hour attribution window, enabling accurate success-based billing (3\% fee) while preventing unjustified charges for organic recoveries.

  \item Built \textbf{Node.js SDK} (\texttt{@mandar1045/resync}, npm-published) and \textbf{Python SDK} (\texttt{resync-sdk}, pip-installable) with full type hints, zero runtime dependencies, HMAC-SHA256 webhook verification, delegated recovery helpers, and comprehensive documentation.

  \item Developed \textbf{Next.js merchant dashboard} with real-time analytics (recovery rates, revenue recovered, failure code breakdowns), autopay management, gateway credential onboarding (Razorpay OAuth Partner flow), webhook configuration, and dunning policy customization.

  \item Deployed \textbf{full observability stack}: Prometheus metrics (per-service gRPC/HTTP latencies, failure code distributions, retry outcomes), Grafana dashboards, Alertmanager with email notifications via Resend, and structured logging with Go's \texttt{slog}.

  \item Containerized all 9 services + infrastructure via \textbf{Docker Compose} (dev) and \textbf{distroless Docker images} ($\sim$20MB each) for production. Infrastructure-as-code with \textbf{Terraform} targeting AWS ECS Fargate. Production deployed on Oracle Cloud Always-Free ARM VM with \textbf{Caddy} auto-HTTPS.

  \item Designed OpenAPI 3.0 specification (800+ lines) covering 15+ REST endpoints with comprehensive request/response schemas, enabling SDK auto-generation and API documentation.
\end{itemize}
